# 7TV Emojis для exteraGram

Плагин загружает глобальные Twitch-эмодзи, а также штатные Twitch-эмодзи и смайлы 7TV выбранных каналов. В настройках можно написать `t2x2, bratishkinoff`; после загрузки наборов коды (например, `Kappa` или `TrollDespair`) показываются изображениями прямо в поле ввода. Триггеры `!`, `:` и `.` не нужны. Глобальные Twitch-эмодзи доступны и без списка каналов.

Версия **0.1** добавляет отдельную вкладку 7TV в панель смайликов exteraGram. В ней доступны глобальные и канальные Twitch-эмодзи, наборы 7TV, поиск, фильтр по аватару канала и подсказки над полем ввода. Коды вставляются без триггеров `!`, `:` и `.`; при одинаковом коде можно выбрать источник. Анимации конвертируются в WEBM и повторно сжимаются при превышении лимита Telegram. Если поля `keywords`/`flags` у `TL_inputStickerSetItem` недоступны в конкретной сборке exteraGram, плагин повторяет добавление без необязательной метки и определяет документ по ID и содержимому набора.

При первой отправке смайла плагин загружает изображение в Telegram, создаёт личный custom emoji-пак и сохраняет полученный `document_id` в локальном кэше. Повторная отправка использует кэш. Если изображение широкое, плагин режет его на квадраты 100×100 пикселей без уменьшения и отправляет фрагменты подряд как несколько custom emoji. Пустые края заполняются прозрачными пикселями.

## Установка

1. Установите файл [`seven_tv_emojis.plugin`](seven_tv_emojis.plugin) через менеджер плагинов exteraGram.
2. Включите плагин и укажите Twitch-каналы в настройках через запятую, пробел или новую строку.
3. Нажмите **Обновить смайлы каналов** и откройте чат. Загружаются глобальные Twitch-эмодзи и наборы настроенных каналов. Для отправки custom emoji нужен Telegram Premium.
4. Откройте панель смайликов, выберите **7TV** и нажмите на нужный смайл. Можно продолжать вводить коды вручную.

Если вкладка не появилась, после открытия панели зайдите в настройки плагина и посмотрите строку **Вкладка 7TV**. В ней указаны результат подключения, число вкладок адаптера и панели либо конкретная ошибка. Диагностика также пишется в лог с префиксом `7TV: picker:`.

В метаданных указаны автор `@F1xTrack`, exteraGram 12.1.1+ и SDK плагинов 1.4.4.3+. Версия плагина — 0.1.

## Как это устроено

- 7TV GraphQL API находит Twitch-канал по точному имени и загружает его активный emote set. Подсказки над полем ввода показывают совпадения с текущим словом, пока поле в фокусе. Совпадающие коды из разных каналов отображаются отдельными вариантами; выбранный источник используется при отправке.
- Вкладка 7TV использует адаптер стандартной панели чата, добавляя четвёртую страницу. Аватары каналов отображаются в горизонтальном ряду сверху и служат фильтром. Превью скачиваются при появлении ячеек в сетке; открытие вкладки не загружает изображения всего набора. Сетка переиспользует ячейки при прокрутке. Поиск не учитывает регистр. При отключении плагина панель возвращается к трём страницам.
- В поле ввода код остаётся текстом; после загрузки превью его рисует Android span. Для GIF используется анимированное превью. Исправление или продолжение слова убирает картинку. Код должен быть отдельным словом, регистр учитывается: `Wide` распознаётся, `!Wide` и `Wide,` — нет.
- При отправке плагин ждёт загрузки отсутствующих смайлов. Если текст, чат или адресат ответа изменились за время загрузки, автоматическая отправка отменяется; обновлённый текст можно отправить обычной кнопкой.
- Telegram-файлы и созданные emoji-паки сохраняются по ID пользователя, отдельно для каждого аккаунта. Для API создания набора используется `stickers.createStickerSet` с флагом `emojis`; последующие фрагменты добавляются через `stickers.addStickerToSet`. Уже загруженные фрагменты сохраняются даже при ошибке следующего фрагмента.
- При создании набора передаются название `SevenTV Emotes` и непустое уникальное короткое имя `SevenTV_<UUID>`. При занятом коротком имени допускается до трёх попыток с новыми именами, без повторной загрузки файла. При отказе сервера код ошибки и отправленные имена записываются в лог плагина.
- Если локальный кэш не знает ни одного пака, плагин сначала запрашивает созданные текущим пользователем наборы через `messages.getMyStickers` и ищет свой прежний emoji-пак по имени или названию. Найденный пак используется повторно. Если поиск завершился ошибкой, новый пак не создаётся.
- Готовый custom emoji может иметь другой ID, чем исходный загруженный файл. Документ сопоставляется по ID загрузки, метке конкретного фрагмента или единственному новому ID относительно пака до добавления. При неполном ответе выполняется одно повторное чтение пака. Метаданные созданного пака сохраняются до поиска документа, чтобы ошибка поиска не создавала ещё один пак при повторной отправке.
- Для анимированных смайлов предусмотрена конвертация GIF в WEBM через встроенный `WebmEncoder` Telegram: квадрат 100×100, до 30 кадров/с, до 3 секунд. Плагин выбирает один из профилей битрейта и частоты кадров, чтобы уложиться в 240 КБ при лимите Telegram 256 КБ. Если сервер всё же возвращает `STICKER_VIDEO_BIG`, текущий фрагмент кодируется заново с более низким качеством и загружается повторно. Длинная анимация воспроизводит полный цикл быстрее, чтобы уложиться в 3 секунды. В конвертации нет масштабирования изображения.

## Ограничения

- Вкладка добавляется для Premium-аккаунта в обычную панель чата с тремя страницами Emoji/GIF/стикеры. Если сборка exteraGram использует другой набор сигнатур методов панели или чат скрывает часть этих страниц, вкладка не добавляется; причина показывается в настройках.
- Требуется встроенный WebM-кодировщик exteraGram для отправки анимации. Если он отсутствует или конвертация не удалась, сообщение остаётся в поле ввода и выводится ошибка.
- Telegram принимает custom emoji размером ровно 100×100. Если оригинальный CDN-файл выше 100 пикселей и нельзя выбрать версию поменьше, изображение разбивается также по вертикали.
- Если Telegram отклонил добавление в удалённый или заполненный набор, плагин создаёт новый. Проверка старых `document_id` на сервере при каждом отправлении не выполняется.

## Проверки

Локальные тесты находятся в `tests/test_plugin.py`: загрузка всех фрагментов перед отправкой, использование и разделение кэша, продолжение прерванной загрузки, смена текста/чата/ответа, таймауты, UTF-16 и сохранение форматирования, нарезка без изменения пикселей, выбор CDN-версии, обработка ошибок PNG/WEBM, объявление Java-прокси обработчика загрузки, поля создания пака и обработка отказа сервера или занятого имени.

Для вкладки 7TV проверяются сохранение трёх штатных страниц, переиспользование страницы и ячеек, поиск и обновление наборов, вставка по UTF-16 и выделению, запрет вставки из старой панели другого чата, ограничения Premium, восстановление панели после отключения и выгрузки плагина в потоке интерфейса, управление фокусом поиска и клавиатурой, загрузка превью только для запрошенных ячеек и объявления Java-прокси слушателей.
Проверки используют имитации Android, JNI и Telegram. Они проверяют логику плагина, но не заменяют проверку Java-моста, WebM-кодировщика, интерфейса и создания emoji-пака на сервере. На шлеме тестирование не проводится.

Android, JNI и Telegram в этих тестах заменены имитациями. Они проверяют логику плагина, но не доказывают работу Java-моста, реального VP9-кодировщика, отображение вкладки и клавиатуры на устройстве и создание emoji-пака на сервере. Проверка новой вкладки в exteraGram пока не выполнена. На шлеме тестирование не проводится.

API и формат: [7TV GraphQL schema](https://github.com/SevenTV/SevenTV/blob/main/apps/website/schema.graphql), [Telegram stickers API](https://core.telegram.org/api/stickers), [требования к Telegram stickers и emoji](https://core.telegram.org/stickers).

Доступ к полям и хуки: [get_private_field](https://plugins.exteragram.app/docs/hook-utils), [Xposed Method Hooking](https://plugins.exteragram.app/docs/xposed-hooking).

Типы результатов Java-моста: [исходный код преобразований Chaquopy](https://github.com/chaquo/chaquopy/blob/master/product/runtime/src/main/python/java/conversion.pxi).
